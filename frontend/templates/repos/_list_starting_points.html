How to read the list signals
List stars and commits
These describe the list's own GitHub repository, not every project it links to. A popular list is not a security or maintenance guarantee.
README repos and indexed repos
README repos counts unique GitHub repositories detected in the README. Indexed repos counts visible repositories saved for that list. The counts can differ; neither covers every kind of resource in a README.
Recently pushed and recently scanned
Pushed describes activity on the list's GitHub repository. Scanned records when Browse Awesome checked the list. Neither proves that a linked project is still maintained.
Choose a project, not just a list
Open a list to narrow its repositories by language or freshness, then verify fit upstream. Use the repository shortlisting guide for a candidate worksheet and the limits of each signal.
