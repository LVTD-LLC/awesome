# Search awesome lists with MCP

Intent owner: `/blog/search-awesome-lists-with-mcp/`.
Audience: developers using an agent to discover indexed GitHub projects.
Action: new how-to, not a second generic repository evaluation guide.

Information gain: a tested list-scoped interaction that exposes pagination,
README truncation and stale catalog observations before the upstream handoff.
The existing shortlist guide retains broader evaluation and trial intent.

## Discovery and verification

Homepage and blog index provide inbound discovery. In-body links lead to the
list directory, self-hosted list, repository search and existing evaluation guide.
The existing Markdown publishing surface owns the route and sitemap entry.
Use the existing slug-scoped Django SVG include convention; never weaken the
Markdown sanitizer for a figure. Match currentColor/light-dark site tokens.

Verify route, canonical, indexability, server-rendered body, social metadata,
BlogPosting/HowTo/BreadcrumbList/FAQPage, source links and actual production
rendering. Preserve catalog data and IndexNow behavior. A valid JSON-LD parse
does not prove Google acceptance or a rich result.

This document is a publishable implementation brief, not the research store or
deployment receipt. Exact research, shortlist, claims, review evidence and lifecycle
remain in private Rowset dataset `c3ed745c-5336-4f89-8022-4990c3ecc5d5`, indexed by
`browseawesome:daily-seo:2026-10-14`.

Reverify when MCP schemas, transport, pagination or README behavior changes.
Results and repository observations can change; do not treat the example as a
permanent ranking or exhaustive inventory.
